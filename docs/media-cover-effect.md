# 媒体封面效果

在客户端的快捷效果中选择「媒体封面」。客户端每秒读取一次 Windows 系统媒体会话，在播放状态下提取封面主色，并通过已有 `0x09 transition()` 指令发送 RGB、当前亮度和 800 ms 过渡时长。相同颜色不会重复发送；封面变化、停止/暂停播放、封面缺失或无法读取时，会平滑过渡到新的颜色或默认颜色。

默认颜色是「快捷颜色」列表的第一项，与矩阵画笔颜色无关。修改默认颜色时，有可用封面则继续显示封面色；没有可用封面则过渡到新的默认颜色。亮度仍由全局 A0 控制，白平衡仍在板端输出层处理，客户端不重复校正。

断线恢复时，先暂停封面输出并从板端 sync 亮度、白平衡等参数，再恢复跟随，避免客户端旧参数覆盖设备。过渡尚未完成时调整亮度，会重新发送新亮度的目标过渡，以免后续动画帧写回旧亮度；过渡已经完成时，只使用 A0 调整，不重复启动动画。

选择其它快捷效果、发送矩阵/预设图案、进入维护模式或退出客户端，会停止封面跟随。客户端保存该效果的选择和默认颜色列表，下一次启动并连接后自动恢复；板端同步只更新亮度、白平衡等板端参数，不会把最后的封面色覆盖成客户端默认色。客户端退出后，板端保留最后一次显示结果，不会自行继续读取媒体。

## 安装与验证

在项目根目录使用客户端虚拟环境安装依赖：

```powershell
& client/.venv/Scripts/python.exe -m pip install -r client/requirements.txt
& client/.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_*.py'
node tests/test_media_ui.js
```

该功能仅支持 Windows，并依赖播放器向系统媒体控制接口提供播放状态和封面。未接入系统媒体控制的播放器或没有封面的媒体会使用默认颜色。封面只在本机内存中处理，不上传、不保存图片，也不控制播放器的播放/暂停。

人工验收时选择「媒体封面」，播放带封面的媒体，切换到主色明显不同的封面，再暂停播放，确认灯色分别平滑跟随和回退；随后切换其它效果或进入维护模式，确认不再被媒体色覆盖。
